# 聊天记录分析插件 (Chat Analyzer)

定时收集群聊/私聊消息，提交给 AI 进行分析审核，帮助管理员快速了解群内讨论主题、氛围变化，以及是否需要介入处理。

## 功能特性

- **定时自动分析**：按配置的时间间隔，周期性收集聊天记录并提交 AI 分析。
- **关键词即时触发**：消息包含预设关键词时，立即触发一次即时分析，无需等待定时周期。
- **手动审核命令**：管理员可通过 `/analyze`（别名：`/审核`、`/分析`）手动对指定群发起即时分析。
- **多群独立策略**：每个群可配置独立的分析策略组合（综合审核、主题分析、舆情监控、活跃度分析、风险检测），互不干扰。
- **静默模式**：当 AI 判断本轮聊天无异常时，跳过报告推送，减少通知噪音。
- **违规消息定位**：分析结果中自动提取需关注/需复核的消息编号，并通过合并转发消息展示原文，方便管理员快速定位。
- **持久化缓冲**：聊天记录缓冲区自动持久化到磁盘，插件重启后不丢失待分析消息。

## 安装

将插件目录放入 AstrBot 的 `addons` 或插件目录下，重启 AstrBot 即可。

```bash
# 通过 Git 克隆
cd astrbot/plugins
git clone https://github.com/makotowu/astrbot_plugin_chat_analyzer.git
```

## 配置

在 AstrBot WebUI 管理面板中对插件进行配置。

### 基础配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `chat_analysis_enabled` | bool | false | 是否启用插件 |
| `chat_analysis_interval_minutes` | int | 30 | 定时分析间隔（分钟），最小 1 分钟 |
| `chat_analysis_max_messages` | int | 0 | 每次分析最大消息数，0 表示不限制 |
| `chat_analysis_skip_silent` | bool | true | 无异常时跳过报告推送 |
| `chat_analysis_target_session` | string | 空 | 全局报告发送目标会话，格式如 `aiocqhttp:GroupMessage:群号`。留空则仅写入日志 |

### 多群独立策略配置 (`chat_analysis_group_configs`)

在 WebUI 中可为不同群配置独立的分析策略，支持模板快速添加：

| 配置项 | 类型 | 说明 |
|--------|------|------|
| `group_id` | string | 目标群号 |
| `presets` | 多选 | 启用的分析策略，支持：综合审核(default)、主题分析(topic)、舆情监控(sentiment)、活跃度分析(activity)、风险检测(risk)、自定义(custom) |
| `custom_prompt` | text | 自定义提示词，当 presets 包含 custom 时生效 |
| `trigger_keywords` | string | 触发关键词，多个用逗号分隔。消息包含任一关键词时立即触发即时分析 |
| `target_session` | string | 该群的报告发送目标，留空则使用全局配置 |

#### 内置模板

- **标准监控**：综合审核 + 风险检测，适用于大多数群。
- **严格监控**：风险检测为主，适用于需要严格内容审核的群。

## 命令

| 命令 | 别名 | 权限 | 说明 |
|------|------|------|------|
| `/analyze` | `/审核`、`/分析`、`/analyze_now` | 管理员 | 手动触发指定群的即时分析 |

用法示例：
```
/审核 123456        # 分析群 123456
/analyze 123456     # 同上
/分析               # 分析当前群（需在群内发送）
```

## 分析策略说明

插件内置 5 种分析策略，各策略专注于不同维度：

| 策略 | 标识 | 关注重点 |
|------|------|----------|
| 综合审核 | default | 整体讨论主题、氛围判断、异常行为、违规内容、处理建议 |
| 主题分析 | topic | 话题占比、话题是否偏离群定位、是否出现敏感/引战话题 |
| 舆情监控 | sentiment | 整体情绪走向、负面信号识别、情绪是否影响群秩序 |
| 活跃度分析 | activity | 互动模式判断、刷屏/灌水/复读检测、单人霸占话题识别 |
| 风险检测 | risk | 广告导流、违法违规、人身攻击、隐私泄露等严格内容审核 |

每个群可自由组合多个策略，AI 会综合各维度输出分析报告。

## 报告结构

AI 分析报告按以下格式输出：

```
【总体结论】 正常 / 需关注 / 建议复核
【摘要】 当前话题、氛围和最值得关注的点
【风险与依据】 抽象风险判断
【处理建议】 管理建议
【定位清单】 需关注或复核的具体消息编号及原因
```

当开启静默模式且本轮无异常时，报告将被跳过，不会推送。

- AstrBot >= 4.5.2
- 已配置可用的 LLM 提供商
